# Pet Journal

A small, installable **Progressive Web App** for keeping profiles of your dogs and
cats: health notes, body measurements, heat cycles, breeder details, and a
picture for each pet.

All data is stored **locally on the device** using IndexedDB. Nothing is sent to
a server, so the journal is private, works offline, and lives only on the phone
or computer where it was entered. Export and import are provided for backups and
moving between devices.

## Features

- Add, edit, and delete dog and cat profiles
- Per-pet details:
  - Assorted information related to the pet
  - Pet photo (resized and stored locally)
- Birthday banner for upcoming birthdays
- Export all pets to a JSON file and import them back on another device
- Installable PWA with offline support and auto-updating service worker

## Tech stack

- **React 19** + **TypeScript**
- **Vite 8** for dev server and build
- **vite-plugin-pwa** / **Workbox** for the manifest and offline service worker
- **react-router-dom 7** for routing
- **styled-components 6** for styling (object syntax), with design tokens in
  `src/styles/`
- **lucide-react** for icons, **Fontsource** for self-hosted fonts
- **IndexedDB** (raw browser API, see `src/db.ts`) for local persistence
- **ESLint 10** (flat config) with `typescript-eslint` and React Hooks rules

## PWA setup

The app is turned into an installable, offline-capable PWA by
[`vite-plugin-pwa`](https://vite-pwa-org.netlify.app/) (configured in
`vite.config.ts`):

- **Web app manifest** — generated by the plugin: name "Pet Journal", standalone
  display, theme/background colours, and `192`/`512` px icons (plus maskable
  variants) and store screenshots.
- **Service worker** — built with **Workbox**. `registerType: 'autoUpdate'` so a
  new version activates automatically; `cleanupOutdatedCaches` removes stale
  caches.
- **Offline precaching** — Workbox `globPatterns` precache all built
  `js`, `css`, `html`, `ico`, `png`, `svg`, and `webp` assets, so the app loads
  with no network connection.
- **Extra assets** — `favicon.svg`, the PWA icons, and screenshots are copied
  into the build via `includeAssets`.
- Because all pet data lives in **IndexedDB** on the device, the app is fully
  functional offline once installed.

## Getting started

```bash
npm install
npm run dev
```

The app runs at the URL Vite prints (default `http://localhost:5173`).

## Scripts

| Command           | Description                                    |
| ----------------- | ---------------------------------------------- |
| `npm run dev`     | Start the Vite dev server with HMR             |
| `npm run build`   | Type-check (`tsc -b`) and build for production |
| `npm run preview` | Serve the production build locally             |
| `npm run lint`    | Run ESLint over the project                    |

## Project structure

```
src/
  App.tsx            Routes and top-level pet state
  db.ts              IndexedDB read/write helpers
  types/pet.ts       Pet data model
  components/        Screens and UI (forms, overview, details, timeline, ...)
  styles/            Colour, spacing, and typography tokens
  utils/             Helpers such as age calculation
```

## Routes

| Path                | Screen               |
| ------------------- | -------------------- |
| `/`                 | Pets overview        |
| `/add-pet`          | Add a new pet        |
| `/pets/:petId`      | Pet details          |
| `/pets/:petId/edit` | Edit a pet           |
| `/settings`         | Export / import data |
| `/about`            | About the app        |

## Data & privacy

Pet records are stored in the browser's IndexedDB database (`pet-journal`) on the
current device only. Clearing site data or uninstalling the PWA removes the
journal, so use **Settings → Export** to keep a backup. Importing a file
overwrites any pet that has the same ID.
